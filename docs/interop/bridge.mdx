---
title: "JavaScript bridge"
description: "Call legacy TypeScript and JavaScript from compiled Forst via the script bridge runtime."
---

Forst can call functions from existing TypeScript and JavaScript modules at runtime.
Use the **`js`** import suffix, configure the **`bridge`** section in `ftconfig.json`, and install **`@forst/runtime`** in your project boundary.

```ft
import "./legacy/payment" js

func main() {
  result := payment.create(100.0, "USD")
  ensure result is Ok()
  println(result.id)
}
```

## Configuration overview

```json
{
  "bridge": {
    "enabled": true,
    "importPolicy": "explicit",
    "runtimeEnabled": true,
    "host": "node",
    "legacyModules": {
      "format": "compiled",
      "precompile": { "outDir": ".forst/js" }
    },
    "bootstrap": "node_modules/@forst/runtime/dist/bootstrap.js"
  }
}
```

- **`bridge.host`**: `node`, `bun`, or `deno` (host-specific support varies by release).
- **`bridge.legacyModules.format`**: `compiled` (default) or `typescript`.
- **Environment**: `FORST_BRIDGE_*` variables override host, socket path, bootstrap, and logging at deploy time.
